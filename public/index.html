Schleswig MCP

Public data about the city of Schleswig, Germany, through a REST API and the Model Context Protocol (MCP).

Available data

The service covers Schleswig city (municipality code 01059075).

  • Water level — live: the latest available PEGELONLINE station reading, with its timestamp and freshness. A gauge reading is not water depth.
  • Addresses — snapshot: official address records with coordinates.
  • Cultural monuments — snapshot: entries from the cultural monument register.
  • Bathing waters — snapshot: reference locations, without current water quality or swimming safety assessments.
  • Charging stations — snapshot: registered infrastructure, without live connector availability.
  • Population forecast — snapshot: indicators containing historical inputs and projected values.

Example requests

All REST endpoints use GET. Dataset lists default to 20 records and allow at most 100 per request. 

GET /api/v1/schleswig/addresses?q=Abelsteg&limit=5
GET /api/v1/schleswig/water-level

View the address example or use the interactive REST reference. MCP clients connect to /mcp; see the connection instructions.

Sources and licenses

Public datasets have dataset-specific licenses, source credits and documented data dates. Responses include this information and any known limitations. German original values are preserved. See the datasource documentation before reusing data.
