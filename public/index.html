Schleswig MCP

Schleswig, Germany · Open data · AGS 01059075

Public Open Data for Developers and AI Assistants

Schleswig MCP provides structured public information about the city of Schleswig through a REST API and the Model Context Protocol (MCP).

An independent open-data project. Not operated or endorsed by the City of Schleswig.

Available data

The service covers Schleswig city (municipality code 01059075). The current water level is live; its daily history and official statistics are updated by a reviewed pipeline; the other five categories use prepared snapshots.

Water level Live · PEGELONLINE
The latest available station reading, with its timestamp and freshness. A gauge reading is not water depth. Unvalidated measurements are not navigation advice, flood warnings or safety assessments.
Water-level history Daily · PEGELONLINE
Daily minimum, mean and maximum per calendar day, appended by a scheduled pipeline after review. The history starts with the first collection run.
Official statistics Annual · Regionaldatenbank
Population, births, deaths and migration, residential construction, tourism and municipal taxes since 2008, as published by the statistical offices.
Addresses Snapshot · LVermGeo SH
Official address records with coordinates.
Cultural monuments Snapshot · Open Data SH catalog
Entries from the cultural monument register.
Bathing waters Snapshot · GovData catalog
Reference locations, without current water quality or swimming safety assessments.
Charging stations Snapshot · Bundesnetzagentur
Registered infrastructure, without live connector availability.
Population forecast Snapshot · GovData catalog
Indicators containing historical inputs and projected values, not current population counts.

Start with a request

All REST endpoints use GET. No API key is required. Dataset lists default to 20 records and allow at most 100 per request. 

GET /api/v1/schleswig/addresses?q=Abelsteg&limit=5
GET /api/v1/schleswig/water-level

View the address example

Sources and limitations

Data comes from public sources. Responses include source, license, date, and limitation information. Most datasets are snapshots; the current water level is retrieved live and its daily history is updated through reviewed pull requests.
