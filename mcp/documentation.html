MCP documentation

Four read-only theme tools provide public data about Schleswig city, Germany (AGS 01059075), grouped by topic. REST and MCP use the same domain functions and return the same domain data.

Independent project. Not operated or endorsed by the City of Schleswig.

Connect

Public endpoint: https://schleswig-mcp-data-seven.vercel.app/mcp. Transport: Streamable HTTP. No API key is required.

In an AI client that supports remote MCP servers, add this endpoint as an HTTP server with no authentication. Connect and discover its tools, then call list_schleswig_addresses with {"limit": 1}. Configuration names vary by client; examples for Inspector and VS Code follow.

The service is stateless. Use an MCP client to initialize, discover tools and call them over POST. GET and DELETE return HTTP 405 because there is no standalone SSE notification stream or stored session to delete. Opening /mcp in a browser is not a connection test.

MCP Inspector

npx @modelcontextprotocol/inspector@2.11.0
  1. Open the local Inspector URL printed by the command.
  2. Select Streamable HTTP and enter the public endpoint above. Use Inspector's proxy connection mode so requests originate from its local backend; direct cross-origin browser requests are rejected.
  3. Connect, list tools, then run list_schleswig_addresses with {"limit": 1}.

CLI discovery:

npx @modelcontextprotocol/inspector@2.11.0 --cli https://schleswig-mcp-data-seven.vercel.app/mcp --transport http --method tools/list

See the official Inspector documentation. Inspector 2.11.0 has produced complete results followed by a Windows/Node.js 24 shutdown assertion in local testing; this is a tooling limitation, not a successful CLI exit.

VS Code configuration

Use this in .vscode/mcp.json, following the documented HTTP server configuration: 

{
  "servers": {
    "schleswig": {
      "type": "http",
      "url": "https://schleswig-mcp-data-seven.vercel.app/mcp"
    }
  }
}

Start the server from VS Code's MCP controls and confirm that its tools appear. This example follows VS Code's documented format; it has not been tested interactively in VS Code. For local development, use http://127.0.0.1:3000/mcp.

Inputs and pagination

get_schleswig_water_level takes {}. All five list tools and the list datasets of the theme tools accept the same optional arguments:

List tool arguments
Argument Type and behavior
id String, 1–100 characters after trimming; exact, case-sensitive ID.
q String, 1–200 characters after trimming; case-insensitive substring search.
limit Integer 1–100; default 20.
offset Integer 0–9007199254740991; default 0.

Use JSON numbers for integers. Unknown arguments, null inputs and empty strings are invalid. id and q combine with AND. No match or an offset beyond the result returns a successful empty page.

Keep the filters and limit unchanged and follow pagination.nextOffset until null. total counts matching records, returned counts this page, and offset and limit echo the applied pagination. Source order is stable within a snapshot but can change after replacement.

Results

Successful calls contain structuredContent and a matching JSON text entry in content. Water level returns station, measurement, freshness, source and notices. List tools return metadata, data, pagination and notices.

Metadata includes the dataset identifier, municipality, data and source dates, provider, publisher, license, required credit and processing notes. Unknown dates and missing nullable values remain null. Preserve source attribution, license URLs and modification notices when reusing data. German original values are retained.

Each example below shows the complete structuredContent, without repeating the identical text entry. Static examples contain one real snapshot record ({"limit": 1}); the water example is synthetic and is not a current measurement. Full property schemas are available through MCP tools/list; the REST reference documents the same domain responses.

Theme tools

Theme tools group related datasets: choose one with the required dataset argument. Results contain the selected dataset and the same domain data as REST in result. List datasets accept the pagination arguments below; the live water level ignores them.

Deprecated single-dataset tools

These tools remain available during a transition period and return the same data without the dataset wrapper. Use the theme tools above for new integrations.

Errors and limitations

Source failures produce isError: true and a JSON text error, without a success structuredContent. For example: 

{
  "isError": true,
  "content": [{
    "type": "text",
    "text": "{\"error\":{\"code\":\"DATA_NOT_FOUND\",\"message\":\"The prepared dataset is missing.\"}}"
  }]
}

Invalid tool arguments and transport errors use the MCP SDK's protocol error handling. Host and Origin checks remain enforced; cross-origin browser calls are unsupported. Requests are limited to 64 KiB, lists to 100 records. Only water level calls an external service at request time; avoid unnecessary polling. Snapshots change only after replacement and restart or redeployment.

Tool schemas use JSON Schema 2020-12. Required nullable properties must be present, but their value may be null. Clients translating schemas to narrower dialects may need their own adaptation.
